# Screenshots

This folder contains screenshots of the Aurelia Grand hotel reservation application.

## How to Add Screenshots

1. Run the application locally (both backend and frontend)
2. Take screenshots of each major page
3. Save them in this folder using the exact filenames below
4. Recommended size: 1920x1080 or similar 16:9 ratio
5. Format: PNG (preferred) or JPG

## Naming Convention

- Use lowercase
- Hyphens (not underscores)
- Descriptive but concise
- Always `.png` extension preferred
